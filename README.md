# ADfied-LAMMPS-and-LMP-Gau

This repository provides all the codes for ADfied LAMMPS and LMP-Gau, as well as the geometry and input files used in the publication.

This file provides a guide to navigate around different folders.



1. ADfied\_LAMMPS\_version\_7Aug\_2019: This is the ADfied version of LAMMPS version 7 Aug 2019
2. ADfying LAMMPS: The instructions and scripts for ADfying different LAMMPS version, if needed
3. LMP\_Gau: The instructions and scripts for LMP\_Gau, the integration between LAMMPS and Gaussian
4. SI\_files: The supporting information files for the publication, including geometries, input files, Hessians, and other setup information.
